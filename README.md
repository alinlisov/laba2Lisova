##  Зміст проєкту

**Тема:** Таблиці в HTML5. Створення зображень засобами трансформацій в CSS3.  
* **Файли:** `index.html`, `style.css`
* **Опис:**
  1. **Завдання 1:** Створення складної HTML5-таблиці з об'єднанням комірок (`colspan`, `rowspan`) за Варіантом №4. Застосовано стилізацію кольорів за формулою (nn = 04) та динамічну зміну кольорів при наведенні курсора (`:hover`).
  2. **Завдання 2:** Верстка графічного елемента «Приціл» засобами CSS3 двома способами:
     * За допомогою позиціонування (`position: absolute`, `z-index`).
     * За допомогою трансформацій (`transform: translate`, `rotate`) та радіальних градієнтів (`radial-gradient`).
